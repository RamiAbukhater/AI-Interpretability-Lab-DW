Resources and glossary

The primary sources, a glossary of every technical term used on this site, and good places to start if you want to learn more interpretability.

Primary sources

  • The paper. Christina Lu, Jack Gallagher, Jonathan Michala, Kyle Fish, and Jack Lindsey. The Assistant Axis: Situating and Stabilizing the Default Persona of Language Models. arXiv 2601.10387, 2026. Read Sections 1 to 4 for this project; Sections 5 and 6 cover activation capping.
  • Anthropic's blog post on the paper: The Assistant Axis. Short and well illustrated; read it first.
  • The paper's code: safety-research/assistant-axis (MIT license). Includes the pipeline, analysis notebooks, and the transcripts used in Section 2.
  • The paper's precomputed vectors: lu-christina/assistant-axis-vectors on HuggingFace, for Gemma 2 27B, Qwen 3 32B, and Llama 3.3 70B.
  • Our lab notebook: persona_axis_kaggle_exercises.ipynb, the Kaggle edition of ARENA's notebook 4.4 that every page on this site walks through.
  • The original ARENA notebook: 4.4 LLM Psychology & Persona Vectors, in ARENA_materials. Our notebook adapts its Sections 1 and 2. Its Sections 3 and 4 cover the related Persona Vectors paper.
  • Related papers. Persona Vectors (Chen et al., 2025), which extracts vectors for specific traits; Sam Marks, The Persona Selection Model; janus, Simulators.

Glossary

Activation
Any intermediate value computed inside a neural network while it processes an input. In this project it almost always means the residual-stream vector for one token at one layer. Used interchangeably with hidden state. See concept 3.
Assistant Axis
The direction in activation space from the average role-playing persona to the average default Assistant, \(\mu_\text{default} - \mu_\text{roles}\), scaled to length 1. Higher projection means more Assistant-like. See concept 5.
Cosine similarity
The cosine of the angle between two vectors, \(u\cdot v / (\lVert u\rVert \lVert v\rVert)\). Ranges from −1 (opposite) through 0 (unrelated) to 1 (same direction), and ignores vector length. See concept 4.
d_model
The number of dimensions of the residual stream, which is the length of every activation vector in it. 3584 for Gemma 2 9B, 2304 for Gemma 2 2B, 4608 for Gemma 2 27B. In Hugging Face it is model.config.hidden_size.
Hidden state
The residual-stream vector for a token after a given layer. Hugging Face returns them with output_hidden_states=True as a tuple with one entry per layer plus the embeddings, each of shape (batch, seq_len, d_model).
Hook (forward hook)
A function attached to a PyTorch module that is called every time the module runs, with its input and output. It can record the output or return a modified one. Used to read one layer cheaply and to steer. See concept 6.
Instruction-tuned (-it)
A model that, after pre-training, was further trained to follow instructions and behave as a chat Assistant. Gemma's instruction-tuned versions end in -it; versions without it are base models that only continue text.
LLM judge (autorater)
A language model used to grade other models' outputs against a rubric, for example the 0 to 3 role-play scale or the delusion-risk rubric. It runs at temperature 0 so grades are consistent. See concept 2.
Mean-centering
Subtracting the average of a set of vectors from each of them, so what remains is how each one differs from the average. Without it, a large shared component makes all persona vectors look alike. See concept 4.
PCA (principal component analysis)
A method that finds orthogonal directions along which a set of points varies the most, ordered by how much variance each explains. Used here to show that persona space has one dominant direction. See concept 5.
Persona
A character the model is asked to play, defined in the notebook by a system prompt. The default Assistant is itself a persona.
Persona drift
A gradual move of the model's activations away from the Assistant end of the axis over a conversation, often alongside out-of-character or harmful behaviour.
Persona vector
The average activation, at one layer, over all response tokens of all kept responses for one persona. One vector of length d_model per persona. (Not the same as the trait vectors in the separate Persona Vectors paper.)
Principal component
One of the directions PCA finds. PC1 is the direction of greatest variance, PC2 the greatest at right angles to PC1, and so on. Its sign is arbitrary.
Projection
The dot product of a vector with a unit-length direction, \(x\cdot a\): how far \(x\) extends along \(a\). Used to place personas and conversation turns on the Assistant Axis.
Residual stream
The vector for each token that passes up through a transformer. Each layer reads it and adds its own output to it, so information accumulates. Reading it at a layer gives that layer's hidden state. See concept 3.
Steering
Changing a model's behaviour by adding a vector to its residual stream during generation, \(h \leftarrow h + \alpha s\). The coefficient \(\alpha\) sets direction and strength. See concept 7.

Other terms used along the way: API key, a secret string that authenticates your requests to a service (setup step 3); KV cache, stored attention keys and values that let generation process one new token per step (concept 6); license gate, a requirement to accept a model's terms before downloading it (setup step 4).

Learning more interpretability

  • 3Blue1Brown, Neural Networks: the visual series on how neural networks and transformers work; chapters 5 to 7 cover transformers and attention.
  • A Mathematical Framework for Transformer Circuits (Elhage et al., 2021): where the residual-stream view used on this site comes from.
  • How To Become A Mechanistic Interpretability Researcher by Neel Nanda, his current guide to getting started.
  • A Comprehensive Mechanistic Interpretability Explainer and Glossary by Neel Nanda.
  • ARENA: the full curriculum this lab borrows from. Chapter 1 covers transformer interpretability from the ground up.
  • Persona vectors blog post: the companion work on trait-specific directions.
  • Steering Language Models With Activation Engineering (Turner et al., 2023): an early, readable paper on activation steering.
