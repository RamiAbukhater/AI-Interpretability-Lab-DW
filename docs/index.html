What this project is about

A large language model learns from an enormous amount of human writing: novels, forum threads, scripts, textbooks, chat logs. To predict all of that well, it has to be able to continue text in the voice of almost anyone. Ask it to be a pirate, a tired nurse, or a ghost, and it can play the part. In that sense a language model is less like one character and more like an actor who knows thousands of roles.

Chat models like Gemma, Claude, or ChatGPT go through a second phase of training, called post-training, that pushes the model to settle on one particular character by default: a helpful, honest Assistant. The other characters do not disappear. A system prompt, a long emotional conversation, or a cleverly framed request can still pull the model toward one of them, and sometimes that is how chat models end up saying strange or harmful things.

The paper we are reproducing, The Assistant Axis (Lu, Gallagher, Michala, Fish, and Lindsey, 2026), looks inside the model to see how this works. The authors have the model play hundreds of characters, record its internal activations for each one, and find that one direction in that space stands out: it separates the default Assistant from everything else. They call it the Assistant Axis. Measuring where the model sits along that direction shows when a conversation is pulling it out of character, and pushing the model along it changes how it behaves. In our notebook you will build that axis yourself on Gemma 2 9B, watch conversations drift along it, and steer the model with it.

How long will this take?

Plan about an hour for setup, most of it waiting for Kaggle and the model license. Each concept page takes 20 to 40 minutes to read alongside the matching part of the notebook. The full 9B run uses roughly 30 to 45 minutes of GPU time, and you have a weekly allowance (see GPU quota).

What you need to know already

  • Python: functions, dictionaries, list comprehensions, and reading other people's code.
  • Basic linear algebra: vectors, dot products, vector length, matrix multiplication. Nothing beyond a first course.
  • A little PyTorch helps but is not required. The concept pages explain every tensor shape.

You do not need any interpretability background. Every technical term is defined in the glossary.
